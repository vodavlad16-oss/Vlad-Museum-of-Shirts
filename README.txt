# Football Shirt Museum

Versiunea 1 a muzeului online, construită în jurul primului exponat:
VfB Stuttgart 2004/05 — Kevin Kuranyi #22.

## Cum îl deschizi
Deschide `index.html` într-un browser. Nu necesită server sau instalare.

## Fotografii
Fotografiile originale sunt în `images/`.

## Următorii pași
1. Adaugă alte tricouri și fotografii.
2. Creează câte o fișă pentru fiecare exponat.
3. Adaugă căutare și filtre.
4. Publică site-ul online.
